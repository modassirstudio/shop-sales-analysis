# Shop Sales Analysis & Dashboard

This is a sales analysis project that I made using Microsoft Excel and real shop sales data.

I made this project to practice Excel, data analysis, Pivot Tables and dashboard making.

## About the Project

The main purpose of this project is to understand the sales and profit performance of the shop.

In this project I am working on:

- Sales analysis
- Profit analysis
- Weekly performance
- Best sales day
- Top products
- Pivot Table analysis
- Dashboard

I am building this project week by week and improving the analysis as I continue.

## Tools I Used

- Microsoft Excel
- Excel Tables
- Pivot Tables
- Pivot Charts
- Excel Dashboard
